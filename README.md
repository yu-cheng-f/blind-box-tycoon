# 盲盒拍卖财富模拟器

单文件 HTML 模拟经营 Demo（无构建、无依赖，双击即玩）。移动端 412×915 竖屏设计，存档写入 `localStorage`。

## 玩法

继承一间社区快递站，靠拆快递盲盒、囤货、送拍、鉴定捡漏，一路从小仓库做到古董寄存柜。

- **快递站**：每日 6 个盲盒额度（成就后 9 个），价格档位随净资产上台阶；开箱结果按「空箱 / 残次 / 仿品 / 杂物 / 真品」分布，真品可当场卖、存库房等行情、或捐博物馆吃日票
- **拍卖行**：每 3 天开市，12 件拍品，图录估值 ≠ 真实价值；落槌才付款，专家当场鉴定
- **压轴大拍**：第 3 张地图起每场最后一件，估值按现金与净资产定价，可「全押」——一场翻倍或一场见底
- **9 张递进地图**：老旧社区 → 盲盒区 → 集装箱 → 机场行李 → 海关码头 → 旧货仓库 → 富豪寄存 → 远洋货仓 → 古董寄存柜
- **交易所**：6 图 + 净资产 15 万解锁，30 只虚构股票、18 只基金、7 类房产，「钱生钱」阶段
- **开局运势**：每档随机求签（顺风顺水 / 偏门手气 / 稳扎稳打 / 霉运当头），仅前 25 天且净资产 15 万以内生效

## 运行

直接用浏览器打开 `盲盒拍卖财富模拟器_demo.html`。存档 key：`ckpm_v18_save`。
